# Korat Node Protocol

The wire protocol for joining the Korat hub as a node and serving MCP tools to agents
through the cloud relay. This directory is self-contained and designed to be extracted
into its own public repository.

## Contents

- `node-gateway.proto` — the gRPC service and messages (`korat.relay.v1`). Canonical
  source; the .NET reference implementation compiles this file in place.
- `SPEC.md` — wire semantics: handshake & auth, heartbeat & presence, publishing,
  session lifecycle, enrollment, payload limits, version negotiation.
- `CRYPTO.md` — node-auth HMAC (live) and relay AES-GCM E2E (deferred milestone).
- `test-vectors/` — language-neutral conformance fixtures generated by the reference
  implementation. Every SDK should assert against these.

## Implementing an SDK

1. Generate gRPC stubs from `node-gateway.proto` for your language.
2. Implement the handshake (§1), heartbeat (§2), and a `SyncMcpServers` reconcile (§3).
3. Implement an in-process MCP server that consumes/produces `RelayFrame` payloads (§4).
4. Verify your crypto against `test-vectors/` (`CRYPTO.md`).

## Reference implementation

C#: `src/Korat.Protocol` (proto + `RelayCrypto`) and `src/Korat.Domain/Auth/NodeAuthTokens.cs`
in the Korat monorepo.
